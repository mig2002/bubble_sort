Zenodo description
This project contains a simple C++ program that demonstrates the Bubble Sort algorithm, one of the basic sorting techniques used in computer science.

What it does
Takes an array of integers
Repeatedly compares adjacent elements
Swaps them if they are in the wrong order
Continues until the array is sorted in ascending order
Purpose
This code is intended for:

learning and understanding sorting algorithms
beginner-level C++ practice
demonstrating how a basic sorting method works in code
